Cyberbullying Prediction System Using Machine Learning

## Overview

Cyberbullying Prediction System is a machine learning-inspired web application that detects offensive and non-offensive text using a simulated ML prediction workflow.

The project demonstrates:

* Cyberbullying detection
* Text classification
* Dataset upload
* Model training simulation
* Data visualization using charts
* Prediction dashboard
* Interactive frontend UI

## Features

* User Login & Registration
* Dataset Upload
* Cyberbullying Prediction
* Model Training Simulation
* Accuracy Analysis
* Confusion Matrix
* Model Comparison Charts
* Responsive Single Page Application

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Machine Learning Simulation
